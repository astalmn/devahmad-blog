# DevAhmad — الموقع العربي

موقع عربي بالكامل مبني باستخدام Astro وTypeScript وCSS، وجاهز للنشر على Cloudflare Pages.

## التشغيل

```bash
npm install
npm run build
npm run dev
```

## Cloudflare Pages

- Build command: `npm run build`
- Output directory: `dist`
- Production branch: `main`
- Node.js: 22

## الصفحات

`/` الرئيسية، `/blog/` المدونة، `/projects/` المشاريع، `/about/` عني، `/resources/` المصادر، `/contact/` تواصل، `/privacy/` الخصوصية.

المقالات والمشاريع العربية في `src/content/`. تم الاحتفاظ بالمحتوى الإنجليزي الأصلي داخل `content-backup-english/` دون نشره.

> ارفع محتويات هذا المجلد إلى جذر المستودع الحالي، وليس المجلد نفسه. راجع بيانات التواصل قبل النشر.
