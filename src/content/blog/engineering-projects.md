## Start with requirements
Write measurable acceptance criteria, constraints and expected failure modes before selecting a framework.

## Plan in small increments
Build a minimal vertical slice: one complete feature spanning UI, business logic and persistence if needed.

## Verify continuously
Use type checking, unit tests, integration tests and repeatable builds. Record architectural decisions when trade-offs are significant.

## Release safely
Separate configuration from source, use version control and define a rollback procedure.
