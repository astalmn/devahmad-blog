تعلم البرمجة لا يحتاج إلى مئة دورة. يحتاج إلى <mark class="text-highlight">تسلسل صحيح + ممارسة + مشاريع + مراجعة</mark>. هذه الخارطة مصممة لتمنعك من البقاء في مرحلة مشاهدة المحتوى دون بناء شيء.

<div class="callout callout-info"><strong>قاعدة:</strong> لا تنتقل إلى أداة جديدة لمجرد أنك سمعت عنها. أضف الأداة عندما يحتاجها مشروعك.</div>

## المرحلة 1: أساسيات البرمجة

تعلم المتغيرات، الأنواع، الشروط، الحلقات، الدوال، المصفوفات/القوائم، الكائنات، التعامل مع الأخطاء، وتقسيم المشكلة إلى دوال صغيرة.

```ts
function calculateTotal(price: number, quantity: number): number {
  if (quantity <= 0) return 0;
  return price * quantity;
}

console.log(calculateTotal(25, 3));
```

المهم هنا ليس حفظ الصياغة، بل فهم <span class="text-success">المدخلات → المعالجة → المخرجات</span>.

## المرحلة 2: <span class="text-accent">Git وGitHub</span>

تعلم دورة العمل الأساسية:

```bash
git init
git add .
git commit -m "Initial project"
git branch -M main
git push
```

بعدها تعلم الفروع، pull requests، حل التعارضات، وكتابة README واضح.

## المرحلة 3: مشروع صغير

لا تبدأ بمنصة ضخمة. ابنِ تطبيق مهام، متتبع مصروفات، صفحة منتجات، أو API بسيط.

<div class="callout callout-tip"><strong>نصيحة:</strong> المشروع الجيد للتعلم يحتوي على شيء لا تعرف كيف تنفذه. إذا كنت تعرف كل خطوة مسبقًا فأنت غالبًا تكرر تدريبًا، لا توسع مهارتك.</div>

## المرحلة 4: قواعد البيانات وواجهات API

تعلم CRUD، HTTP، JSON، المصادقة الأساسية، ثم SQL. لا تحفظ أوامر SQL منفصلة؛ اربطها ببيانات مشروع حقيقي.

| المفهوم | ما يجب فهمه |
|---|---|
| GET | قراءة البيانات |
| POST | إنشاء بيانات |
| PUT/PATCH | تعديل البيانات |
| DELETE | حذف البيانات |
| SQL | تخزين واستعلام البيانات |

## المرحلة 5: الاختبار والتصحيح

تعلم قراءة رسالة الخطأ وStack Trace، استخدام debugger، كتابة اختبار لوظيفة حساسة، وفصل سبب المشكلة عن أعراضها.

<div class="callout callout-warning"><strong>خطأ شائع:</strong> نسخ رسالة الخطأ إلى أداة AI ثم تطبيق أول جواب دون فهمه. اطلب تفسير السبب، اختبر الفرضية، ثم راجع التغيير.</div>

## المرحلة 6: النشر

انشر مشروعك. النشر يكشف أشياء لا تظهر محليًا: متغيرات البيئة، البناء، المسارات، CORS، قواعد البيانات، وإدارة الأسرار.

## نظام أسبوعي قابل للاستمرار

- يومان: تعلم مركز.
- ثلاثة أيام: بناء المشروع.
- يوم: إصلاح وتحسين وقراءة توثيق.
- يوم: مراجعة وكتابة ما تعلمته.

<div class="callout callout-important"><strong>هدف الخارطة:</strong> بعد عدة أشهر يجب أن يصبح لديك مستودع يمكن تشغيله وشرحه، وليس مجرد قائمة دورات مكتملة.</div>
