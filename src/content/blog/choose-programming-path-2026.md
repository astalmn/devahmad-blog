اختيار المسار ليس قرارًا عن **أفضل لغة برمجة**، بل عن نوع المشكلات التي تريد حلها ونوع المنتجات التي تريد بناءها. الخطأ الشائع هو الانتقال بين JavaScript وPython وC# كل أسبوع لأن كل فيديو يقترح طريقًا مختلفًا.

<div class="callout callout-info"><strong>معلومة:</strong> لا تحتاج إلى اختيار تخصصك النهائي من اليوم الأول. المطلوب أولًا اختيار مسار واحد يكفي لبناء مشروع حقيقي، ثم إعادة التقييم بعد اكتساب خبرة عملية.</div>

## ابدأ من المنتج الذي تريد بناءه

اسأل نفسك سؤالًا بسيطًا: **ما الشيء الذي أريد أن أراه يعمل أمامي بعد ثلاثة أشهر؟**

| إذا كنت تريد بناء | المسار الأقرب | بداية عملية |
|---|---|---|
| مواقع وتطبيقات ويب | Web Development | HTML + CSS + JavaScript/TypeScript |
| تطبيقات هاتف | Mobile | Flutter أو React Native أو Native |
| أنظمة وخدمات خلفية | Backend | Node.js أو Python أو Java/.NET |
| أدوات AI وتحليل بيانات | AI / Data | Python + SQL |
| ألعاب | Game Development | C# مع Unity أو TypeScript/JavaScript لألعاب الويب |

## لا تختَر بناءً على اللغة وحدها

اللغة أداة. المسار يتضمن أيضًا قواعد البيانات، Git، الاختبار، النشر، قراءة التوثيق، وفهم بنية التطبيق. لذلك سؤال «هل أتعلم Python أم JavaScript؟» أقل فائدة من سؤال «هل أريد بناء API أم واجهة ويب أم نموذج بيانات؟».

<div class="callout callout-tip"><strong>نصيحة:</strong> اختر مسارًا يسمح لك ببناء شيء يهمك شخصيًا. المشروع الذي ترغب فعلًا في استخدامه يعطيك سببًا للاستمرار عندما تصبح الدروس أصعب.</div>

## اختبار 7 أيام قبل الالتزام

1. اختر مسارًا واحدًا فقط.
2. شاهد مقدمة قصيرة عن أدواته.
3. نفّذ تطبيقًا صغيرًا جدًا.
4. اكتب بيدك بدل نسخ المشروع كاملًا.
5. حاول إصلاح خطأ واحد بنفسك.
6. اقرأ صفحة واحدة من التوثيق الرسمي.
7. قيّم التجربة: هل استمتعت بالمشكلة أم فقط بالنتيجة؟

## متى تعرف أن المسار مناسب؟

ليس عندما يصبح كل شيء سهلًا. المؤشر الأفضل هو أنك تستطيع تحمل صعوبة المسار لأن **نوع المشكلة نفسها يثير اهتمامك**.

<div class="callout callout-warning"><strong>تحذير:</strong> لا تغيّر المسار لمجرد أنك وصلت إلى أول موضوع صعب. التشتت بين المسارات قد يعطي شعورًا بالتقدم بينما يمنع تراكم المهارة.</div>

## خطة أول 90 يومًا

### الشهر الأول: الأساس
تعلم أساسيات اللغة، المتغيرات، الشروط، الحلقات، الدوال، هياكل البيانات الأساسية، ثم Git.

### الشهر الثاني: البناء
ابنِ مشروعين صغيرين بدون متابعة فيديو خطوة بخطوة. استخدم التوثيق والبحث عند الحاجة.

### الشهر الثالث: مشروع Portfolio
اختر مشكلة واضحة، اكتب المتطلبات، نفّذ نسخة أولى، اختبرها، انشرها، ثم وثّق ما تعلمته.

<div class="callout callout-important"><strong>الخلاصة:</strong> المسار الصحيح ليس الأكثر ضجة، بل المسار الذي تستطيع فيه بناء مشاريع متزايدة الصعوبة والاستمرار في التعلم.</div>
