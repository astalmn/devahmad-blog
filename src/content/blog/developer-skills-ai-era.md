عندما يصبح توليد الكود أسرع، ترتفع قيمة المهارات التي تحدد **أي كود يجب أن يوجد، وهل هو صحيح، وهل يصلح للإنتاج**.

استطلاع Stack Overflow 2025 يعكس هذا التوتر: استخدام أدوات AI واسع، لكن الثقة بدقتها أقل بكثير من نسبة الاستخدام. هذا يجعل التحقق مهارة أساسية لا خطوة إضافية.

## 1. تفكيك المشكلة

المطور القوي يحول الطلب الغامض إلى متطلبات وحدود وحالات فشل ومعايير قبول.

## 2. قراءة الكود

إذا استطاعت أداة توليد مئات الأسطر، تصبح قدرتك على فهم الـdiff واكتشاف الافتراضات الخطأ أكثر أهمية.

## 3. Debugging

تعلم Logs وbreakpoints وnetwork inspector وstack traces وصنع minimal reproduction.

<div class="callout callout-tip"><strong>تدريب مفيد:</strong> عندما يقترح AI إصلاحًا، حاول قبل تطبيقه كتابة سبب تتوقع أنه أصل المشكلة. بعد الاختبار قارن فرضيتك بالنتيجة.</div>

## 4. الاختبار

لا يكفي أن تقول «يعمل عندي». تعلم unit/integration/e2e، واختر المستوى الذي يحمي السلوك المهم.

## 5. الأمن

إدارة الأسرار، التحقق من المدخلات، المصادقة مقابل التفويض، إدارة الاعتماديات، ومبدأ أقل صلاحية أصبحت ضرورية حتى للمشاريع الصغيرة.

## 6. تصميم الأنظمة

تعلم حدود المكونات، تدفق البيانات، قواعد البيانات، caching، queues، failure modes، ومراقبة النظام. لا تحتاج إلى هندسة موزعة لكل مشروع؛ تحتاج إلى اختيار التعقيد المناسب.

## 7. التواصل التقني

README جيد، issue واضح، commit مفهوم، وقرار معماري موثق يوفر وقت الفريق والأدوات الآلية معًا.

| مهارة | لماذا تزداد أهميتها؟ |
|---|---|
| Problem decomposition | تحدد المهمة قبل توليد الحل |
| Code review | تتحقق من مخرجات أسرع |
| Testing | يحول الثقة إلى دليل |
| Security | يقلل أثر الأتمتة الخاطئة |
| System design | يحدد الحدود والقرارات |
| Communication | يوفر سياقًا للبشر والأدوات |

<div class="callout callout-warning"><strong>لا تهمل الأساسيات:</strong> استخدام AI لا يعوض فهم اللغة وHTTP وقواعد البيانات وGit. بدون نموذج ذهني جيد يصبح اكتشاف المخرجات الخاطئة أصعب.</div>

## المهارة الأهم

ليست كتابة Prompt طويل. إنها القدرة على الانتقال من **مشكلة → فرضية → تنفيذ → اختبار → مراجعة**، سواء كتبت الكود بنفسك أو استعنت بأداة.

<div class="callout callout-important"><strong>الخلاصة:</strong> اجعل AI يسرّع التنفيذ، واجعل معرفتك الهندسية تحكم جودة النتيجة.</div>
