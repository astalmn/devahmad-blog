## نبذة عن المشروع

**ذكاء بلس** مشروع ويب أعمل على تطويره لتجميع مجموعة من أدوات الذكاء الاصطناعي في تجربة عربية بسيطة، مع دعم اللغة الإنجليزية وإمكانية إضافة أدوات جديدة مستقبلًا.

المشروع **قيد التطوير**؛ لذلك أعرض هنا ما تم بناؤه فعليًا وما هو مخطط له بوضوح، دون تقديم الأدوات غير المكتملة على أنها جاهزة.

## الهدف

الفكرة هي بناء منصة واحدة يمكن أن تضم أدوات عملية للمستخدم بدل توزيعها على خدمات وصفحات منفصلة، مع التركيز على:

- واجهة عربية واضحة وسهلة الاستخدام.
- دعم العربية والإنجليزية.
- بنية قابلة لإضافة أدوات جديدة.
- حسابات مستخدمين ومصادقة.
- نشر المشروع كتطبيق ويب يمكن الوصول إليه من المتصفح.

## ما تم تنفيذه

- إنشاء واجهة المشروع باستخدام **React + TypeScript + Vite**.
- بناء هيكل المنصة وتجربة التنقل الأساسية.
- إضافة دعم واجهة عربية وإنجليزية.
- العمل على نظام تسجيل الدخول والحسابات باستخدام **Supabase**.
- ربط المشروع بعملية نشر على **Cloudflare Pages**.
- تجهيز الواجهة لاستيعاب مجموعة من أدوات الذكاء الاصطناعي.

## الأدوات المخطط لها

تتضمن خارطة المشروع أدوات مثل:

- مولد الـ Prompts.
- تحويل الصوت إلى نص.
- منشئ السيرة الذاتية.
- أدوات الكتابة والتلخيص والترجمة.
- محادثة بالذكاء الاصطناعي.
- مولد أكواد برمجية.

> هذه الأدوات جزء من خطة تطوير ذكاء بلس، ولا يعني إدراجها هنا أن جميعها مكتمل أو متاح حاليًا.

## التقنيات

| التقنية | الاستخدام |
|---|---|
| React | بناء واجهة المستخدم |
| TypeScript | تطوير أكثر أمانًا وتنظيمًا |
| Vite | بيئة البناء والتطوير |
| Supabase | المصادقة وخدمات الخلفية |
| Cloudflare Pages | نشر المشروع على الويب |
| GitHub | إدارة الشيفرة والإصدارات |

## تحديات التطوير

من أبرز الجوانب التي تم العمل عليها أثناء تطوير المشروع استقرار عملية النشر، وضبط متغيرات البيئة، وربط خدمات المصادقة، ومعالجة مشاكل الواجهة والتنقل بين اللغتين.

## حالة المشروع

**قيد التطوير النشط.**

أعمل على تطوير المنصة تدريجيًا وإكمال الأدوات وربطها بالخدمات المطلوبة قبل اعتبارها إصدارًا نهائيًا.

## تشغيل المشروع

**ذكاء بلس** متاح للاستخدام مباشرة عبر المتصفح. استخدم زر **تجربة المشروع** أسفل الصفحة لفتح المنصة وتجربتها.
